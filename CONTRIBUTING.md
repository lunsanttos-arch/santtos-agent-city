# Como contribuir

A SanTTos Agent City é um projeto comunitário de jogo isométrico para acompanhar agentes de IA.

1. Consulte o ROADMAP.md e abra ou comente uma issue sobre a mudança.
2. Use uma branch dedicada e abra um Pull Request com resumo, testes e imagens (para arte/UI).
3. Nunca adicione tokens, cookies, chaves, arquivos pessoais ou repositórios privados de terceiros.
4. Crie sprites e músicas originais ou utilize material com licença compatível; não copie recursos de Pokémon ou Nintendo.
5. Ao contribuir para um conector, explique como autentica, confirma conexão e obtém estados reais.
6. Não implemente push, merge, deploy ou operações destrutivas automáticas sem revisão.

A licença de reutilização ainda será escolhida pelo mantenedor; o arquivo LICENSE será adicionado antes de aceitar contribuições substanciais.
